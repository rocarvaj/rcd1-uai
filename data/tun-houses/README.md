## Diccionario de datos: `tunisian-houses.csv`

Este conjunto de datos contiene información de viviendas en Túnez, incluyendo precio, ubicación, características físicas y amenidades.

| Variable            | Descripción                                                                                         |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| id                  | Identificador único universal de 128 bits.                                                          |
| price_tnd           | Precio del inmueble en dinares tunecinos (TND).                                                     |
| price_eur           | Precio del inmueble en euros. Convertido el 29 de octubre de 2022 con una tasa de 1 TND = 0.31 EUR. |
| location            | Barrio donde se ubica el inmueble.                                                                  |
| city                | Ciudad del inmueble.                                                                                |
| governorate         | Gobernación del inmueble (de las 24 gobernaciones de Túnez).                                        |
| area                | Superficie del inmueble en metros cuadrados.                                                        |
| room                | Número de habitaciones.                                                                             |
| bathroom            | Número de baños.                                                                                    |
| age                 | Antigüedad del inmueble en intervalos; 0 indica que es nuevo.                                       |
| state               | Estado del inmueble: 1 = estado normal, 2 = requiere renovación, 0 = completamente nuevo.           |
| latt                | Latitud.                                                                                            |
| long                | Longitud.                                                                                           |
| distance_to_capital | Distancia entre el inmueble y la capital, Túnez.                                                    |
| garage              | Booleano, indica si tiene garaje.                                                                   |
| garden              | Booleano, indica si tiene jardín.                                                                   |
| concierge           | Booleano, indica si tiene conserjería.                                                              |
| beach_view          | Booleano, indica si tiene vista al mar.                                                             |
| mountain_view       | Booleano, indica si tiene vista a la montaña.                                                       |
| pool                | Booleano, indica si tiene piscina.                                                                  |
| elevator            | Booleano, indica si tiene ascensor.                                                                 |
| furnished           | Booleano, indica si está amueblado.                                                                 |
| equipped_kitech     | Booleano, indica si la cocina está equipada.                                                        |
| central_heating     | Booleano, indica si tiene calefacción central.                                                      |
| air_conditionting   | Booleano, indica si tiene aire acondicionado.                                                       |
